วิชาภาคบังคับ KALASIN UNIVERSITY

การออกแบบและสถาปัตยกรรมคอมพิวเตอร์

ศึกษาการทำงานของซีพียู หน่วยความจำ การประมวลผลคำสั่งเชิงตรรกะ และโครงสร้างสถาปัตยกรรมระดับฮาร์ดแวร์ของระบบคอมพิวเตอร์สมัยใหม่

#ComputerArchitecture #Assembly #Microprocessors
ระบบอินเทอร์เน็ตของทุกสิ่ง KALASIN UNIVERSITY

Internet of Things (IoT) & Smart Control

การเชื่อมต่อเซนเซอร์ บอร์ดไมโครคอนโทรลเลอร์ (ESP32/Arduino) ผ่านโปรโตคอล MQTT และ HTTP เข้าสู่คลาวด์เพื่อการควบคุมและวัดค่าแบบเรียลไทม์

#ESP32 #MQTT #SmartSensors
การพัฒนาเว็บ KALASIN UNIVERSITY

Full-Stack Web Development Projects

การออกแบบและพัฒนาเว็บไซต์ฝั่ง Frontend ร่วมกับ Backend Database จัดการข้อมูลผู้ใช้งานอย่างปลอดภัย ตอบสนองรวดเร็วบนทุกอุปกรณ์

#WebEngineering #DatabaseDesign #ResponsiveUI
การสื่อสารข้อมูล KALASIN UNIVERSITY

Computer Networks & Security

การออกแบบระบบเครือข่ายคอมพิวเตอร์ การตั้งค่า Subnetting, Routing Protocol และมาตรการความปลอดภัยเบื้องต้นในองค์กร

#CiscoRouting #NetworkTopology #CyberSecurity
